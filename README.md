A lightweight C++ game engine built from the ground up.

## Introduction
ART Engine is an Open Source, multi-platform engine. It provides a simple workflow to create fantastic videogames.

ART Engine is written in **C++20**.

## Dependencies
ART Engine relies on the following third-party libraries:

* **[GLFW](https://www.glfw.org/)** - Window management and input.
* **[GLAD](https://glad.dav1d.de/)** - OpenGL API Loader.
* **[GLM](https://github.com/g-truc/glm)** - OpenGL Mathematics library.
* **[JSON](https://github.com/nlohmann/json)** - JSON parsing library.
* **[OpenAL Soft](https://github.com/kcat/openal-soft/)** - Audio rendering library.
* **[AngelScript](https://www.angelcode.com/angelscript/)** - Scripting Language library.
* **[ReactPhysics3D](https://www.reactphysics3d.com/)** - Physics library.
* **[EnTT](https://github.com/skypjack/entt)** - ECS library.
* **[TinyglTF](https://github.com/syoyo/tinygltf/)** - glTF loading library.

## Building
The project is currently in **early development**. 

It is officially developed and tested using **Code::Blocks** with the **MinGW** toolchain. Detailed, multi-platform build instructions (such as CMake support) will be added as the engine matures.
