# ANGEL RISING TECHNOLOGY ENGINE
A lightweight C++ game engine built from the ground up.

## Features
- Rendering with OpenGL
- Audio with OpenAL Soft
- Model loading with TinyglTF
- Scripting with AngelScript
- ECS system with EnTT

## Requirements
- C++20
- MingW
